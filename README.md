# Student Dropout Risk Analysis – FoCS 2026

This project is part of my Foundations of Computer Science coursework at the University of Milano-Bicocca.

The project uses Python and pandas to analyze a dataset of 100,000 student records and identify factors related to student dropout.

The analysis includes student attendance, missed deadlines, GPA changes, working hours, and a risk score calculated from different student conditions.

I also used GDP per capita data from Our World in Data to merge country information with the student dataset and compare dropout rates across continents.

## Tools Used
- Python
- pandas
- Jupyter Notebook

## Project Files
- `student_dropout.ipynb` – Contains the code, results, and explanations for Questions 1–9, including my AI usage declaration.
- `student_dropout_risk_2026.csv` – Student dataset used for the analysis.

## How to Run
Open `student_dropout.ipynb` in Jupyter Notebook or VS Code and run the cells in order.

The GDP per capita dataset is loaded directly from Our World in Data in Question 8.
